# Change to 24-hour time

## Abstract
How to change to 24-hour time format via Ubuntu Terminal Window

## Procedure
1. Open a Terminal window
2. Use the gsettings command:
```
gsettings set org.gnome.desktop.interface clock-format '24'
```

>[!TIP]
>Use '12' for 12-hour time.
