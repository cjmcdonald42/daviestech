# Change 12h/24h time format via CLI

## Abstract
How to change 24hr time via Ubuntu Terminal Window

>[!TIP]
>If you want to set it back to 12hr time then in the apostrophes change it to '12' instead.

## Procedure
1) Press the ubuntu logo
2) Open up the app thats named "Terminal"
3) Open it and type this in "gsettings set org.gnome.desktop.interface clock-format '24'
4) And there you have it!
